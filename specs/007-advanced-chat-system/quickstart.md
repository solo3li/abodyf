# Quickstart: Advanced Chat System

## Overview
This feature introduces a comprehensive upgrade to the chat platform, including a dedicated private inbox, custom offers, rich media attachments, and dynamic voice recordings.

## Verification Steps

### 1. Private Inbox & Messaging
1. Login as a Student. Navigate to an Executor's profile or service page.
2. Click "Contact Provider".
3. Verify a private chat opens (no order associated).
4. Send a text message.
5. Login as the Executor and verify the message appears in the new "Inbox" tab.

### 2. Custom Offers
1. Inside the Private Chat as an Executor, click "Create Custom Offer".
2. Enter details (Title, Price, Days, Description) and send.
3. Switch to the Student view. Verify the offer appears as a distinct widget.
4. Click "Accept" and verify it redirects to the checkout/order creation flow.

### 3. Rich Media Attachments
1. In any chat, click the attachment icon.
2. Upload an image (JPG/PNG). Verify it displays inline as a thumbnail.
3. Upload a document (PDF). Verify it displays as a downloadable file link.
4. Attempt to upload a file > 20MB. Verify the system rejects it with an error.

### 4. Voice Recording & Visualization
1. In the chat input, press and hold the microphone icon.
2. Speak into the device. Verify a real-time waveform animates.
3. Release the button to stop. Listen to the preview.
4. Send the recording.
5. In the chat feed, click play on the voice message and verify the audio plays with a static waveform visualization.
